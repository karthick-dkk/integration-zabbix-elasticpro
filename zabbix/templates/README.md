# ElasticPro templates (Zabbix 7.0)

The four templates ElasticPro feeds, copied from the ElasticPro repository at v0.3.10
(`deploy/zabbix/template-*.yaml`, where they are generated by `tools/zabbix-*-template.mjs`
— that is the one place they are edited; this folder is a copy for a Zabbix that is set up
from this project alone).

| File | Template | Fed by |
|---|---|---|
| `template-elasticpro.yaml` | **ElasticPro automation** — the automation rules' verdicts per cluster, from the JSON document `tools/elasticpro-scrape.mjs` writes; one HTTP item, no agent | the automation scraper |
| `template-elasticpro-alerts.yaml` | **ElasticPro alerts** — every alert the Alerts page raises, as Zabbix problems | the automation scraper |
| `template-elasticpro-client-plan.yaml` | **ElasticPro client plan** — the volume report per cluster (the Volume widget's columns come from it) | the plan scraper |
| `template-elasticpro-log-delay.yaml` | **ElasticPro log delay** — the scheduled log-delay measurement | the core's delay sink |

Import: *Data collection → Templates → Import*, or `deploy/zabbix/setup/zbx_phase34.py` in the
ElasticPro repository, which imports all four in order. Then `master/import.py` here, then
*Write master template* on the Clients page.
